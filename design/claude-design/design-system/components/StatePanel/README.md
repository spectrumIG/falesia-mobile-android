# StatePanel

Centered empty or error state that replaces a screen's or section's content when there is nothing to show.

- Provide: an icon in a 72px circle, a title, one or two sentences, and up to two actions (primary `Button`, secondary `fm-link`).
- Neutral (`primary-10` circle) for empty results; error (`fm-state-error`, `danger-soft` circle) when something failed.
- Say what happened, why if known, and the next step. No error codes or stack traces; put technical detail behind "Show details" if needed.

# RouteRow

A featured route on crag details: grade box, name, star rating with count, type and length.

- Provide: grade, name, rating (0–5 stars, filled with `FILL 1`) and number of ratings, type (Sport, Trad, Mixed), length.
- Row: `surface-row`, `primary-10` border, `radius-xl`, padding `space-3`; the grade box is `size-grade-box`, `radius-lg`, `primary-20` fill, grade in `stat` `primary`.
- Type in `ink-dim`, length in `ink-faint`, both `caption`.

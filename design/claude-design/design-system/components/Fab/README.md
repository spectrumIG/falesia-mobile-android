# Fab

Floating action button for the screen's main add action.

- `size-fab`, `primary` fill, `on-primary` `add` icon at 30px, `shadow-xl`; fixed `space-6` from the right and `space-24` from the bottom.
- Square with `radius-lg` (crag details) or round with `fm-fab-round` and `shadow-lg` (route list). Stitch's logbook uses `radius-xl`.
- Always give it an `aria-label` ("Add route", "Log ascent").

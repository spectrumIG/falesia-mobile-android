# SectionHeader

A section title with an optional text action on the right.

- Provide: the title and, optionally, the action label ("Map View", "SEE ALL", "View All", "Add Note").
- Title: `section-title` for the first section of a list screen, `card-title` on crag details, `title-sm` for Beta & Notes.
- Action: `fm-link` in `primary`; `fm-link-strong` (700, uppercase, trailing `chevron_right`) for SEE ALL; a leading `edit` icon for Add Note.

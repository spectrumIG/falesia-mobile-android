# Tag

Short uppercase labels: the climbing style of a crag, a route's status, the way an ascent was made.

- Style pill (`fm-tag`): `primary-20` fill, `primary` text, `radius-full`. Solid variant (`fm-tag-solid`) with an icon for WORLD CLASS on the hero.
- Route type (`fm-tag-sm`): `primary-10` fill, `radius`, no tracking.
- Route status (`fm-status`): SENT in `success`, PROJECT in `primary`, both with a border.
- Ascent (`fm-ascent`): FLASH `success`, REDPOINT `info`, ONSIGHT `special`, others (MULTI-PITCH) `primary`.
- One or two words. Color is never the only signal: the word is the label.

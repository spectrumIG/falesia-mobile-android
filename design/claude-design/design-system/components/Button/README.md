# Button

Full-height text buttons with a leading icon, used in pairs at the end of route details.

- Primary (`fm-btn-primary`): `primary` fill, `on-primary` label, `shadow-primary`. One per screen.
- Secondary (`fm-btn-secondary`): `button-secondary` fill, `ink` label.
- `size-button` tall, `radius-xl`, label in `button`. In a pair both take `fm-btn-block`.
- Icon buttons are `fm-icon-btn` (round, `size-icon-button`), with `fm-icon-btn-primary` for the card chevron and `fm-icon-btn-tonal` for the map toggle.

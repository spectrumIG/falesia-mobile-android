# CragHero

Full-width photo at the top of crag details, with a badge, the crag name and its location on a gradient.

- Provide: photo (as `background-image`), an optional badge (`fm-tag-solid`, e.g. WORLD CLASS), name, location.
- At least 40% of the viewport tall (338px on a 390×844 phone); no radius on phones.
- The `scrim` gradient runs from the bottom to transparent at half height; text is `ink-on-photo` and `ink-on-photo-muted`.

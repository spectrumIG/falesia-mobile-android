# LogEntry

An ascent in the logbook: thumbnail, route, location, grade and style, then ascent tags and the date.

- Provide: thumbnail photo, route name, location, grade, discipline (Trad, Bouldering, Sport), one or two ascent tags (`Tag`, `fm-ascent`), date.
- Card: `surface-card-neutral`, `line-neutral` border, `radius-xl`, padding `space-4`; footer above a `line-neutral-divider`.
- Older entries may fade with `fm-log-dim` (80% opacity), as the third entry does in Stitch.

# BottomBar

The app's four destinations: Discover, Logbook, Ticklist, Profile.

- Items: `explore` Discover, `menu_book` Logbook, `check_circle` Ticklist, `person` Profile; label in `caption`.
- Active item: `primary`, filled icon, weight 600, `aria-current="page"`. Inactive: `nav-inactive` (below 3:1, kept as in Stitch).
- `bg` fill, `primary-10` top hairline, padding `space-2` top, `space-6` bottom; content max 448px wide.
- Detail screens reached from Discover keep Discover active.

# FilterChip

Horizontal, scrollable row of filters that open a picker; the first chip is selected.

- Provide: a short label and the `expand_more` icon (or a leading `tune` icon for the Filters chip in the route list).
- Discover: `size-chip` tall, `radius-xl`, `chip` fill and `chip-ink` label; selected is `primary` with `on-primary` and weight 600.
- Route list (`fm-chip-sm`): `size-chip-sm` tall, `radius-lg`, `primary-10` fill with a `primary-20` border.
- Rows scroll sideways (`fm-chips`), never wrap.

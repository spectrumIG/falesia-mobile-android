# InfoTile

A small boxed fact: label and value, in three layouts.

- Quick info (`fm-tile`, three across): `primary` icon, label in `caption` `ink-muted`, value in `stat`. Crag details: Approach, Sun, Routes.
- Route facts (`fm-tile-start`, two across): uppercase `primary` label, value in `tile-value`. Topo: Grade, Height, Style, Gear.
- Stat (`fm-tile-stat`, three across): uppercase `primary` label, value in `stat-xl`; the one that matters most is `fm-tile-highlight` (`primary` fill, `on-primary`, `shadow-primary`). Logbook: Sends, Hardest, Days.
- All `radius-xl` with a `primary-20` border, except the highlighted tile.

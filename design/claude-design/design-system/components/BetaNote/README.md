# BetaNote

A climber's note about a route: initials avatar, name, relative time, text.

- Provide: author name and initials, time ("2 days ago"), the note text.
- Card: `note` fill, `note-line` border, `radius-xl`; body in `body-sm-relaxed` `ink-secondary`; time in `ink-dim`.
- Stitch shows notes from other people. The app is read-only today, so treat this as a future feature.
